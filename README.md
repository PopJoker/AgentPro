# Real Estate & Property Management System

一個專為物業管理與精選代管物件打造的租屋展示系統。具備現代化 UI/UX 互動設計、絲滑的彈窗轉場動畫，並深度整合 LINE 預約諮詢與開發者資訊。

[瀏覽開發者部落格](https://popjoker.github.io/pop-blog/)

---

## 專案亮點

*   流暢互動轉場：全站彈窗採用 Vue Transition，結合背景淡入淡出與卡片微縮放。
*   響應式 UI 設計：使用 Tailwind CSS 打造行動端與電腦版自適應排版。
*   高效行動呼籲 (CTA)：一鍵加 LINE 線上諮詢、等高 QR Code 行動條碼展示區塊。

---

## 技術棧

*   Framework: Vue 3 (Composition API)
*   Styling: Tailwind CSS
*   Build Tool: Vite
